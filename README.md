# 📱 TechNews Today

## 📋 Descrição da Atividade

Nesta atividade foi desenvolvido um portal de notícias sobre tecnologia chamado **TechNews Today**.

A página apresenta uma notícia em destaque sobre Inteligência Artificial, uma seção de vídeo, uma área de inscrição em uma newsletter e um rodapé com informações de contato.

O projeto foi desenvolvido utilizando **HTML5 e CSS3**, trabalhando conceitos de estruturação de páginas, estilização, formulários, incorporação de vídeos e responsividade.

## 🎯 Objetivo

O objetivo da atividade foi criar uma página moderna de notícias utilizando recursos do HTML e CSS, aplicando diferentes elementos e estilos para deixar a página mais organizada e visualmente atrativa.

## 💻 Tecnologias Utilizadas

- HTML5
- CSS3
- YouTube
- Visual Studio Code

## 📰 Estrutura da Página

A página foi dividida em algumas partes principais:

### 📱 Cabeçalho

O cabeçalho apresenta o nome **TechNews Today** e uma frase de destaque sobre as novidades do mundo da tecnologia.

Também foi utilizado um efeito de gradiente no texto do logo. :contentReference[oaicite:2]{index=2}

### 🚀 Artigo em Destaque

A página possui uma notícia em destaque sobre Inteligência Artificial e seu impacto no desenvolvimento.

Também foi utilizado o elemento `<details>` para criar a opção **"Leia mais"**, permitindo visualizar uma informação adicional sobre a notícia. :contentReference[oaicite:3]{index=3}

### 📺 Vídeo

Foi adicionada uma seção chamada **"Tech em vídeo"**, contendo um vídeo incorporado do YouTube por meio de um `<iframe>`. :contentReference[oaicite:4]{index=4}

### 💌 Newsletter

A página possui um formulário de newsletter onde o usuário pode:

- Informar seu e-mail;
- Escolher uma área de interesse;
- Aceitar os termos;
- Realizar a inscrição.

As áreas de interesse disponíveis são:

- Inteligência Artificial;
- Desenvolvimento Mobile;
- Tecnologias Web. :contentReference[oaicite:5]{index=5}

### 🦶 Rodapé

No final da página foi criado um rodapé com informações de direitos autorais e contato. :contentReference[oaicite:6]{index=6}

## 🎨 Estilização com CSS

O arquivo CSS foi utilizado para deixar a página com uma aparência moderna.

Foram utilizados:

- Gradientes;
- Efeito de transparência;
- Bordas arredondadas;
- Efeitos de `hover`;
- Grid Layout;
- Cores personalizadas;
- Responsividade.

O fundo principal da página utiliza uma tonalidade escura e o conteúdo possui cards com gradientes e bordas arredondadas. :contentReference[oaicite:7]{index=7} :contentReference[oaicite:8]{index=8}
